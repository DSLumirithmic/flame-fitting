Boundary annotation

Annotator:
Mouse: left-click = add point to current stroke; drag a point to move it; wheel = zoom; right-drag = pan.
Keys: N new stroke, U toggle certain/uncertain, C toggle closed, Backspace delete last point, Del delete stroke, [ ] select stroke, Ctrl+S save, PgUp/PgDn prev/next item (saves), F fit view.
Green = certain, orange dashed = uncertain. Points every ~5-10 px along the edge are enough.
